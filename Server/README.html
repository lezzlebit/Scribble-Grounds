Hi! This is all important information:

You'll need Python 3 to run the server script.

You can start it quickly with start.bat (if this doesn't work, try editing it to use "python" instead of "python3")

In order for people on other networks to connect to your server, the script has to be running, and your address has to be port-forwarded!
If you don't know how to do that, it's the same process that's required to let people join a locally-run Minecraft server.
You can change the port in config.txt.

This is my first time writing a web server of any kind. It's messy and mostly built for me to use.
But I'm releasing it to others, since I don't wanna close off the only method of hosting a server (in case I stop hosting one.)
If you host a server, I would highly recommend that you only let people you trust join it, since:

  • There are no moderation tools
  • I don't trust my server code enough to be secure against random people with a lot of time

So run it at your own risk. You should also set a server password in config.txt.

If you're good at writing web servers, and you want to help me make a better web server, that would be awesome.
