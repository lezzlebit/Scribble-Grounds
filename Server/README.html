Hi!

You'll need Python 3 to run the server script.
You can start it quickly with start.bat.

In order for your friends to connect to your server, the script has to be running, and your address has to be port-forwarded!
If you don't know how to do that, it's the same process that's required to let people join a minecraft server.
You can change the port that the server selects in config.txt.

This is my first time writing a web server of any kind. It's messy and mostly built for me to use.
But I'm releasing it to others, since I don't wanna close off the only method of hosting a server (in case I stop hosting one.)
If you host a server, I would highly recommend that you only let people you trust join it, since:

  • There are no moderation tools
  • I don't trust my server code enough to be secure against random people with a lot of time

If you're good at writing web servers, and you want to look at the server code and completely re-write it to be better, I would be very happy. (Seriously)
But if you do, please don't use AI to make it. I am more than happy to explain how the script works myself.
